# **App Name**: TLV Check

## Core Features:

- Phone Login: Phone number login with OTP verification.
- QR Code Scanner: QR code scanner interface for check-in and check-out.
- Reset Password: Allows users to reset their password via phone verification.
- Member Profiles: User profiles associated with names and other relevant information.
- Attendance Report: Generate attendance reports for church officials, which shows historical attendance.
- Personalized message generation: LLM tool helps to suggest personal messages based on historical attendance, when it is low.

## Style Guidelines:

- Primary color: Dark purple (#52135A) for the main background, creating a sophisticated and spiritual atmosphere.
- Background color: Desaturated purple (#5A2162) to provide depth while maintaining visual harmony.
- Accent color: Gold (#FFCC00) for text and accents to highlight important information and provide a luxurious feel.
- Headline Font: 'Playfair' (serif) for headings, offering elegance and formality.
- Body Font: 'Roboto' (sans-serif) for body text, ensuring readability and simplicity for smaller text elements.
- Note: currently only Google Fonts are supported.
- Use simple and elegant icons in gold to match the overall design.
- Keep the layout clean and intuitive, focusing on easy navigation for all users.
